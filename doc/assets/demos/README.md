# Interactive demo assets

`hamiltonian_yamada_phase_map.html` contains the saved Hamiltonian/Yamada phase
map and representative geometry. Sphinx copies it into the documentation asset
tree.

- SHA-256: `dbc11cdeb5b76ca023ebdcaa47c3d0e6b38146629f5c7666a91d8f369edc8777`
- Embedded payload version:
  `hamiltonian_yamada_plotly_region_geometry_v14_nodal_only`
- External runtime dependency: Plotly 2.35.2 from the pinned jsDelivr URL in the
  HTML header.

The source notebook uses a newer regeneration identifier. To update the saved
viewer, generate a candidate, compare its payload and verification outputs,
check the visual presentation, then update the checksum and website together.

The additional material demos are generated by
`dev/build_phase_map_demos.py` from the pinned originals under
`User_guide/applications/NewPhaseMapPlots`. Their region JSON is loaded on demand.
The generated `new_phase_maps/manifest.json` records source and region hashes;
the generated folder is not committed. Sphinx packages the saved scientific
records during HTML builds. The nodal viewer and the material viewers
are separate demo assets.
