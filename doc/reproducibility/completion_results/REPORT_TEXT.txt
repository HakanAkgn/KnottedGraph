1. Computations and the objects they describe
A parameterized solid and a selected graph extracted from that solid carry different equivalence questions. We
therefore retain three separate objects: the analytic sublevel set, its finite closed-voxel realization, and the
embedded graph obtained by checked elementary collapses. Polynomial values label the selected embedded graphs;
regularity certificates describe continuation of the analytic solids. Neither object is silently substituted for the
other.
The complete Hamiltonian scan contains 7,140 points at 1203, with 60 interpolation samples including both
endpoints.
The spacing is 1/59.
The five energy-prefix lengths are 16, 24, 16, 24 and 39, taken from
linspace(0.30,5.25,50). The three TPMS grids contain 1,323 points at the same voxel resolution, retaining
λ ∈linspace(0,1,21) and c ∈linspace(0,0.3,21).
Every originally timed-out noncavity graph was retried without changing its vertices or polyline points. Forty
generic projections were ranked by crossing count before bounded exact evaluation. Two distinct completed
projections were required to agree for a subcubic spatial value; higher-valence results remain fixed-diagram values.

Figure 3: A separate analytic-continuation map in the same presentation. Colors label connected components of the
certified regular-rectangle cover, locally within each family. Gray rectangles contain a proved stationary event; white
rectangles remain unresolved. Distinct colors are not asserted to be distinct ambient-isotopy classes. The lower geometries

does not itself prove analytic-to-voxel correspondence.
The first event search fixed λ and enclosed the resulting critical level. The additional calculation instead fixes a
level inside the requested rectangle and treats λ as an unknown. For an interior event it solves
∇hλ(x, y, z) = 0,
hλ(x, y, z) −c = 0.
(1)
On the spherical wall, the square system is
∇hλ −µ(x, y, z) = 0,
x2 + y2 + z2 −R2 = 0,
hλ −c = 0.
(2)
Numerical roots propose boxes only. For each accepted box, both interval backends recompute a strict Krawczyk
inclusion and a contraction bound below one. The entire λ enclosure must lie inside the query rectangle, the fixed
level must lie inside its level interval, and a bulk box must lie strictly inside the ball. The new method certified
256 further rectangles without relaxing these acceptance conditions.

5. What the voxel audit establishes
A deformation retract can preserve homotopy while the original voxel object has singular local neighborhoods. We
therefore tested every lattice-vertex link of every original sampled mask. The occupied octants form a triangular
subcomplex of an octahedral sphere. An interior manifold vertex has the complete sphere as its link; a boundary
manifold vertex has a disk. The implementation checks incidence, connectedness, all link-vertex links, Euler
characteristic and the boundary cycle for all 256 octant patterns.

This is an exact finite incidence test of the chosen closed-voxel realization. Face-sharing cubes pass, whereas cubes
meeting only at an edge or a point fail. Disconnected balls and a shell remain valid manifolds with boundary.
Passing does not imply that a shell is a handlebody or that a voxel object is ambient-isotopic to its analytic
source.
Comparison within a common analytic certificate
The package also searches for pairs of original TPMS sample points lying in one certified regular analytic rectangle.
For every retained example it freshly replays that rectangle’s complete regularity certificate with both interval
backends and retains both sampled sources and available graph witnesses. Up to twelve examples of each type are
retained: 12 digital-homology conflicts and 12 selected-spine signature variations.
When the digital Betti tuples differ inside one such rectangle, the two voxel realizations cannot both recover the
homotopy type of their analytically isotopic source solids. A difference of selected-spine polynomials alone has
a weaker implication: it demonstrates that this extracted signature is not constant across the certified source
family, but does not isolate whether discretization or the choice of spine causes the difference. The exact cases,
coordinates and certificates are in continuum_vs_digital_witnesses.json.
The central exact singularity
For the retained Schwarz-P-to-Diamond field,
hλ = (1 −λ)(cos x + cos y + cos z)
+ λ(cos x cos y cos z −sin x sin y sin z),
(3)
the critical branches c = 1 −2λ at (π, 0, 0) and c = 2λ −1 at (π, π, 0) are exact. At λ = 1/2, c = 0, the whole
line (π, t, 0) inside the ball is stationary. A certificate requiring an isolated unique gradient root cannot cover a
segment of this line. Exact branch witnesses therefore complement, rather than replace, the local isolated-root
calculation.

The environment is pinned by uv.lock; execution uses Python 3.13 with uv sync –all-extras –group dev
–group docs –frozen. OpenMP, OpenBLAS and MKL thread counts are one. Original cells had a 90-second

The categorical arrays, exact coefficient legends, geometry identities and physical parameter edges are retained in
figure_source_data.json. The CSV files provide all original points, baseline and final statuses, and provenance
hashes. The data/ directory retains the merged records, event certificates, per-mask manifold tests and comparison
witnesses. Full representative geometry is in representatives/. The larger full-grid masks and collapse archives
remain in the twenty original run artifacts. Actions retention is 30 days; it is not a permanent research-data
deposit.
Manuscript integration
The package supplies a separate manuscript insertion draft and corrected figure captions. It does not reconstruct
the unavailable current 42-page manuscript source. Earlier September drafts are not silently substituted for that
source. Author, affiliation and funding information is not invented. The all-word formula work and existing cavity
implementation are unchanged, and no result has been merged into the protected integration branch.
The correct Reidemeister-II condition for the manuscript is that the same physical strand passes over at both
crossings of the cancellable bigon. This figure-independent wording is included in the insertion draft; no claim is
made that the absent original TikZ source was edited.
Claims that remain separate
Completing the finite parameter scans does not supply a complete classification of analytic solids into distinct
ambient-isotopy classes. The regularity cover proves positive continuation within its connected components; event
certificates prove existence of stationary events; the voxel collapse and link tests characterize the represented
cubical complexes; and normalized subcubic polynomials characterize the selected spatial graphs. A theorem or
certificate connecting these different objects must be supplied before stronger identifications are made.
