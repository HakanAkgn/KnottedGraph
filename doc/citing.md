# Cite KnottedGraph

If you use KnottedGraph, please cite the software paper:

Hakan Akgün, Xianquan Yan, Kehan Liu, Zhaoyun Chen and Ching Hua Lee.
**KnottedGraph: Scalable knotted-graph topology for scientific and mathematical
discovery** (2026). [arXiv:2609.31152](https://arxiv.org/abs/2609.31152).

For scientific applications of KnottedGraph to handlebody topology, Fermi-surface
dispersions, Lifshitz transitions and topological phase maps, please also cite:

Hakan Akgün, Xianquan Yan and Ching Hua Lee.
**Topological classification through knotted graphs: Fermi surface dispersions
and Lifshitz transitions** (2026).
[arXiv:2609.13390](https://arxiv.org/abs/2609.13390).

Download {download}`both BibTeX entries <../CITATION.bib>` or use GitHub's
**Cite this repository** button, which reads the repository's `CITATION.cff`.
Record the source commit and calculation parameters alongside the citation;
the paper identifier alone does not identify a software checkout.
